## 检查与边界

源码清单/资源/CMake-qmake 对齐检查、Home scroll、UI loading、playback start
gate 的实际策略检查、shell 语法及 `git diff --check` 均通过。URL 选择的
Qt/C++ 检查在性能阶段完成，签名与同轨道保持、普通 HTTPS 首选保持及回退
行为均通过；发布未再修改该逻辑。

三档字号、横竖屏、单/双列及各页面的视觉覆盖见
[布局审计](layout-audit-20261014.md)，最终布局候选包与本正式包使用同一
功能源码；本次重新核对正式包页面截图和播放行为。前后台、Cover/PiP、直播、
锁屏、软件解码、历史续播、多 P 与冻结恢复等较广回归在前两阶段完成，见
[播放性能](playback-performance-20261014.md) 和
[界面加载](ui-loading-audit-20261014.md)，不将其全部记作正式附件重跑。

实机覆盖限于上述 5.2 设备；5.1 为 SDK 构建目标，标准 RPM 不适用于 5.0。
5.0 仍需独立 SDK 实验包及对应设备验证。搜索在布局阶段遇到上游 HTTP 412，
错误状态排版已检查，没有绕过认证或风控；所有账户内容接口和 UHD 真实
硬解未在本次发布复测中穷尽验证。

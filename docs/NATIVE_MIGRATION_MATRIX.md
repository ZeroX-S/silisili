# Native migration matrix

The stable `silisili-sailfish-1.0.0-7` implementation remains in the tree as the behaviour reference. A native
area is marked device-verified only after it has run on the Pixel 3a XL with Sailfish OS 5.1.0.11.

Last device-installed development baseline: `silisili-native-devel-1.1.0-0.32.aarch64` (SHA-256
`17d4a4b78c64bddd70c36ed9b9ae693081dd52999fc2b79e8670448f4caab5ba`, installed `2026-08-05`).
The in-progress 0.33 source is built for the actively tested Sailfish OS 5.1.0.11 target and is explicitly **not
device-verified** until a new RPM is installed and tested. Older 0.7/0.6 records remain historical functional evidence;
Sailfish OS 5.0.0.62 is no longer the default development build target.

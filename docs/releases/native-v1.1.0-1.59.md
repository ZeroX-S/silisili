## 自 1.58 以来的完整变更

上一版本：[native-v1.1.0-1.58](https://github.com/ZeroX-S/silisili/releases/tag/native-v1.1.0-1.58)。
[完整源码比较](https://github.com/ZeroX-S/silisili/compare/native-v1.1.0-1.58...native-v1.1.0-1.59)。

### 播放加载与快进定位

- 当同一媒体轨道的首选地址为 peer/非标准端口时，优先使用接口给出的常规
  HTTPS 备选地址；常规首选保持原样。保留签名、编码、画质和账号策略，
  不通过降低分辨率换取速度，也不改变直播解析。
- 新定位可以取消过期的 FFmpeg 读取和定位操作；连续拖动按最后目标处理，
  在同一个解复用器/解码器内继续，不把取消误当成播放结束。
- 目标帧实际进入队列后才确认就绪；定位时释放旧 GPU 槽位并保留共享纹理宿主，
  避免音频已定位、视频仍等待时误触发重建。正常冻结恢复继续保留。

### 界面数据加载

- 取消详情页评论等待 3 秒、推荐等待 7 秒，以及逐条延迟显示；详情就绪即请求，
  用有界异步预览分摊界面创建工作，返回页面复用已有或在途请求。
- 首页、直播、评论/回复、搜索、动态、番剧、个人内容和消息列表统一提前约一屏
  预取，合并滚动/布局通知，支持短页与旋转后的分页；失败后等待明确重试。
- 推荐/热门保存页面快照与游标，切回分类直接恢复；同一资源刷新保留已有内容，
  账户、分类和收藏夹之间继续隔离数据。
- UP 空间改为按行插入的虚拟列表，减少追加作品/动态时重建全部卡片的开销。
- 封面、头像和配图按显示尺寸请求 CDN 缩略图并复用缓存；保留签名 URL、已有
  转换、动画和其他域名，减少正常取消图片请求时的日志开销。

### 字体、卡片和横屏排版

- 统一内容字号、1.12 倍行高、截断和文字层级，保留小/中/大三档选择。
- 修复相关推荐固定行高导致标题、UP 主、播放量与相邻卡片压叠的问题。
- 列表行按封面和文字的实际高度留白；图片、文字均在整行内对齐。消息按完整
  行数裁切，分集长标题可换行并撑高点击区域。
- 首页和直播网格按真实字体高度预留文字空间；横屏采用左图右文，保留单/双列
  设置，让标题和作者信息能与封面同时显示。
- 导航说明和较长正文增加合理换行、宽度边界及间距。布局专项没有改动播放器、
  账户和接口事件处理；本版本同时包含上面列出的已验证播放和加载修改。

### 构建与验证

- 新增独立启播/定位计时和界面加载探针，补充 URL 选择、分页及请求去重检查。
- 在 Pixel 3a XL / Sailfish OS 5.2.0.16 上检查三档字号、横竖屏、单/双列及新截图；
  验证普通启播、暂停/播放中定位、连续拖动、360P/480P/720P/1080P/1080P60 切换。
- 正式包的问题片源首帧约 1.48 秒，定位约 1.34～1.62 秒；1080P60 参考片源
  首帧约 1.30 秒，定位约 1.95～2.36 秒，连续拖动最后目标约 0.26～0.35 秒。测试以请求/目标帧计时，
  不包含整段应用冷启动，也不是所有片源或网络的速度承诺。
- 正式包的 1080P60 全屏连续播放超过 60 秒，视频呈现窗口最低约 56.8 FPS，
  无低于 45 FPS 的窗口；正式附件的身份和复测结果见下方发布验证记录。

本附件面向 **Sailfish OS 5.1/5.2 AArch64**，原生开发包继续标记为 prerelease。
**标准 RPM 不适用于 5.0**；5.0 仍需独立 SDK 实验包与对应真机验证。
搜索可能受到上游 HTTP 412 限制，本轮未绕过认证或风控；并非所有账号内容接口、
设备及 UHD 解码均已完成实际验证。
